# enshwick-world

Internal part of [Enshwick](https://github.com/enshwick/enshwick); depend on
[`enshwick`](https://crates.io/crates/enshwick), which re-exports every item
here under its own paths.

The world domain: the live world and its entities, the map, voxels and
terrain, the weather and the time of day, the altars, buffs and game
settings, and the typed handles that read the generated items in a live
world.
