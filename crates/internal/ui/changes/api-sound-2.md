### Added

- `sound::play`, `sound::stop_all`, `Place`, `Play`, `SoundHandle`,
  `SoundState`, `PlayFailure`, `MAX_FADE`, `MAX_STARTS` and `Sounds`, the
  namespace a script reaches them through.
- `NewVoiceover`, `VoiceLine`, `VoiceoverId`, `NewMusic`, `MUSIC_VOLUME`
  and `DAY`, with the base handle's voiced lines and music.
- `sound::play_for`, `Audience`, `RemoteSound`, `MAX_PLAYS` and
  `MAX_RADIUS`, with `Sounds::play_for` for scripts.
