# enshwick-core

Internal part of [Enshwick](https://github.com/enshwick/enshwick); depend on
[`enshwick`](https://crates.io/crates/enshwick), which re-exports every module
here at its own paths.

The safe layer over the binary interface and every domain of the modding API:
`Load`, the world, content, the interface, messages between mods and the fake
host for tests.
