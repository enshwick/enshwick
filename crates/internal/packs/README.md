# enshwick-packs

Internal part of [Enshwick](https://github.com/enshwick/enshwick); depend on
[`enshwick`](https://crates.io/crates/enshwick), which re-exports every item
here under its own paths.

The packs domain: data packs, the items, recipes, workshops, loot, rewards,
sounds and texts a mod describes in TOML files instead of code, and its
changes of vanilla values.
