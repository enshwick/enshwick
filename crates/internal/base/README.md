# enshwick-base

Internal part of [Enshwick](https://github.com/enshwick/enshwick); depend on
[`enshwick`](https://crates.io/crates/enshwick), which re-exports every item
here under its own paths.

What every domain of the API shares: the host handle, events, services,
points, settings, texts, state and the resource codec, below the domains
and the `Load` they hang from.
