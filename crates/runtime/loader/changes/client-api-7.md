### Added

- The rebind and setting client commands, which the Mods screen's page
  makes through its own key capture and field, and the quit command, which
  posts the game's own quit at the main menu. A rebind or setting whose
  page closes before the screen takes it ends unavailable, and a quit is
  cancelled when play starts or a join or host runs before it posts.

### Changed

- The window commands and the Mods screen's changes share one desk for the
  asks a draw of the loader's interface acts on.
