# Furniture comfort

Every piece of furniture gives more comfort inside a base, twice vanilla by
default, so a modest house reaches a long rested bonus. Only the best piece of
each comfort category counts, as in vanilla.

## Settings

`mod-configs/furniture-comfort.toml`, written on first start:

```toml
multiplier = 2.0
```

`multiplier` goes from 0 to 100; 1 is vanilla. An edit takes effect about a
second after saving the file, without a restart.

## Install

Download [`enshwick-furniture-comfort.zip`](https://github.com/themaiby/enshwick/releases/latest/download/enshwick-furniture-comfort.zip),
always the newest version of this mod, and extract it into the folder that
holds `enshrouded.exe` or `enshrouded_server.exe`. It needs Enshwick Loader:
[`enshwick-loader.zip`](https://github.com/themaiby/enshwick/releases/latest/download/enshwick-loader.zip)
alone, or [`enshwick.zip`](https://github.com/themaiby/enshwick/releases/latest/download/enshwick.zip)
with every mod.

## Who needs it

Only the server. Players without the mod see the higher comfort and rested time;
item tooltips keep their vanilla numbers. It does not count in the join check.
