# Bigger stacks

A data pack that lets wood logs, wood planks, stone, resin and charcoal stack
to 999 in one inventory slot.

The idea comes from [Max Stack](https://www.nexusmods.com/enshrouded/mods/111)
by viktoriusssss on Nexus Mods. This pack shares no code or data with it.

A world saved with these stacks depends on the pack: read
[stack sizes and saved worlds](../../book/src/content/packs.md#stack-sizes-and-saved-worlds)
before you remove it.
