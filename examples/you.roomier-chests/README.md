# Roomier chests

A data pack that gives each storage box more slots, more for the bigger ones:
one row of 8 for the smallest, up to five rows for the largest.

The idea comes from [Chest Slots](https://www.nexusmods.com/enshrouded/mods/84)
by Johnson1893 on Nexus Mods. This pack shares no code or data with it.

Boxes placed before the pack keep their size; boxes placed or upgraded after
it get the new one. Removing the pack leaves every box as it is.
