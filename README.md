# Enshwick

A mod loader and modding API for [Enshrouded](https://enshrouded.com), in one
project, with the mods built on it. The loader sits next to the game or the
dedicated server; each mod is a DLL in the `mods/` folder beside it.

## For mod authors

How the repository is laid out, checked and released:
[docs/conventions/](docs/conventions/). Contributions follow
