# Furniture comfort

Every piece of furniture gives more comfort inside a base, twice vanilla by
default, so a modest house reaches a long rested bonus. Only the best piece of
each comfort category counts, as in vanilla.

## Settings

`mod-configs/furniture-comfort.toml`, written on first start:

```toml
multiplier = 2.0
```

## Who needs it

Only the server. Players without the mod see the higher comfort and rested time;
item tooltips keep their vanilla numbers. It does not count in the join check.
